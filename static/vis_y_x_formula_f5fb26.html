Algebraic Properties of Quadratic Function y = x²

Mathematical properties, standard forms, domain, range, and axis of symmetry.

$$f(x) = a(x - h)^2 + k \quad \text{where } a = 1, h = 0, k = 0$$

Variable Breakdown & Units

x Independent Variable
Domain: x in (-inf, inf)
y Dependent Variable
Range: y in [0, inf)
Vertex Extremum Point
(0, 0) global minimum

Derivation & Step-by-Step Logic

Even Function
$$f(-x) = (-x)^2 = x^2 = f(x)$$
Symmetric across Y-axis.
Derivative
$$\frac{d}{dx}[x^2] = 2x$$
Slope is 2x.
Practical Worked Example:
For x = 3: y = (3)² = 9. For x = -3: y = (-3)² = 9.
